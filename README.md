# Lienry Drones

Marketing site for Lienry Drones: a resident cleaning drone that lives on a property and keeps its exterior clean with nobody on site. Sydney, concept stage, raising pre-seed.

## Stack

Next.js 16 (App Router, Turbopack), TypeScript, Tailwind CSS 4, Motion for React, native scrolling, React Three Fiber, zod. Two typefaces, both self-hosted from Fontsource and loaded with `next/font/local`: Instrument Serif for headings and Inter, with its optical size axis, for body, navigation, buttons, labels and numerals. `font-display: swap`, size-adjusted fallbacks, and a preload for the two files used above the fold. `node scripts/fonts.mjs` copies the files out of the packages into `src/fonts`.

## Run it

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # production build
npm run start      # serve the build
npm run lint       # eslint
npm run typecheck  # tsc --noEmit
```

Copy `.env.example` to `.env.local` if you want enquiries forwarded to a webhook (`ENQUIRY_WEBHOOK_URL`) or a different public URL (`NEXT_PUBLIC_SITE_URL`). Without them the site builds and runs; enquiries are logged on the server.

## Media pipeline

AI visuals are generated with Higgsfield, logged in `docs/MEDIA.md`, and listed with their result URLs in `scripts/media/manifest.json`. `npm run media:fetch` downloads them, writes AVIF and WebP images at several widths, compressed MP4 and WebM video under 4 MB with a poster, and `public/media/index.json`, which the site reads to decide what to render. Any asset id that is not in the index shows a labelled placeholder, so the site never breaks while renders are pending. Raw downloads and finished output are cached in `.next/cache/lienry-media`, so a second run only restores files; each index entry records the source URL it was made from, so changing an asset's URL in the manifest refetches it instead of restoring the old files, and files no entry lists are pruned. The approved design sheets the renders are made from live in `docs/references`.

The same script runs in two other places. As a `prebuild` step it runs in soft mode before every `next build`, so a host with open internet (Vercel, Netlify) downloads and optimises the whole set on its first build and restores it from the build cache on later builds, while a machine that cannot reach the CDN keeps the placeholders and still builds. On GitHub Actions ("Fetch and optimise media" in the Actions tab, once Actions is enabled for the repository) it commits the result back to the branch. Video compression needs ffmpeg: `ffmpeg-static` is a dev dependency, so the build must install dev dependencies (the default on Vercel), and a system ffmpeg works too.

## Quality checks

`npm run screenshots` captures every route at 1440 and 390 wide into `docs/screenshots` (start the site on port 3011 first). Accessibility was checked with axe-core at both widths; motion respects `prefers-reduced-motion`; the 3D building falls back to an SVG or video on phones and low-power devices.

`node scripts/record-software-view.mjs` records the software view with Playwright, one stepped frame at a time (`?capture=wide` and `?capture=tall` put the page on a hand-driven clock), and encodes the 12 s loops in `public/video` with ffmpeg for phones and reduced motion. Two more scripts back the header, shape and scrolling work: `npm run shots:set -- docs/screenshots/after` captures every route at 1440 and 390 (top of page and full page) into a folder, and `npm run perf:scroll` scrolls the home page with real wheel events and reports frame rate, frames over 50 ms, long tasks and the hottest script functions. `node scripts/compare-shots.mjs before after out` builds side-by-side sheets from two capture folders.

## Header and type

The header is a 72px bar: the five nav links pinned hard left, the mark alone centred as the link home, and Register interest hard right in a 4px-radius rectangle with a solid ink fill, a white label and an arrow. The active link carries a hairline underline. Over the home hero the bar is transparent and reads white on the film's own scrim; past 80px of scroll it becomes a solid plaster bar with a hairline and ink text. The full bar needs 1024px, because below that the absolutely centred mark would run into the left links, so phones and tablets get the mark, a hamburger and a full-screen menu instead.

`npm run contrast -- <frame.jpg>` proves the bar stays legible. It composites the film frame, the 25% ink veil and the header scrim per pixel and reports the worst pixel behind each element, first against the supplied frame and then against pure white, which no frame can exceed. It gates the button on its white hairline, because WCAG 1.4.11 asks for 3:1 on a component's visual boundary rather than its fill. A third gate replays the 300ms scroll swap: the bar crossfades its background and steps the text colour once at 70ms, because interpolating both walks the text through its own background (1.00:1 at the worst frame against 4.05:1 stepped).

Type is two families and one scale. Headings are Instrument Serif at weight 400, sentence case, 1.05 to 1.15 leading and -0.02em. Everything else is Inter with optical sizing, body at 1.55 with no letter spacing. Labels are the only uppercase on the site: Inter 500, 12px, 0.12em. Every step is a `clamp()` that lands on its stated pixel value at 390 and at 1440: display 64 to 96, H1 44 to 64, H2 32 to 44, H3 24 to 28, body 17 to 18, small 14. Numerals in the counters, the software panel and the labels are tabular so nothing shifts while a value animates.

The measure is 68 characters, and the token that delivers it is `45ch`, not `68ch`. CSS `ch` is the advance of the digit zero, which Inter renders at 0.65em with optical sizing on, while a character of this site's prose averages about 0.47em; `68ch` sets 91 characters a line. 45ch was found by counting the glyphs on every rendered line of all 172 paragraphs on the site at both widths, and brings the longest line anywhere to 66.

## Brand

The mark is three building silhouettes with the flight arc cut through them, supplied by Liam and traced into a vector. `public/brand/lienry-mark.svg` is the master (ink on transparent, 529 x 785 box); `src/components/ui/Wordmark.tsx` inlines the same three paths so the mark fills with the current text colour on light and dark surfaces. In the header the mark stands alone, centred, as the link home; the name "Lienry Drones" lives in the browser tab title and the footer. `scripts/icons.mjs` renders every raster brand file from the vector: `favicon-16x16.png`, `favicon-32x32.png`, `favicon.ico`, `apple-touch-icon.png` (180), `icon-192.png`, `icon-512.png` (also the JSON-LD logo) and `site.webmanifest` in `public`, plus a 1024px raster of the mark alone. `src/app/icon.svg` is the scalable favicon, ink on light browser themes and plaster on dark ones. `scripts/og.mjs` renders the Open Graph image with the site's fonts. The original file sits in `docs/brand/lienry-mark-source.png`.

## Honesty rules baked in

No customers, logos, testimonials, results, prices, certifications or approvals are claimed anywhere. Statistics come only from `src/content/stats.ts`, each verified against and cited to its primary source. The founders' photos are placeholders until real photos are supplied.

The imagery is AI-generated. It used to carry a "Concept render" caption under every figure, and a footer line saying so; both were removed on request, so a visitor now has nothing on the page telling them these are renders rather than photographs of a working product. `docs/MEDIA.md` still records every asset with its prompt and model.

## Deploy

Any Next.js host works. On Vercel, import the repository and set `NEXT_PUBLIC_SITE_URL` and, if you want form delivery, `ENQUIRY_WEBHOOK_URL`.
